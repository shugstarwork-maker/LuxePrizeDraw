# Luxe Prize Draw audio assets

Replace the temporary Web Audio fallback tones by adding licensed files with these names:

- `button.mp3`
- `ticket-select.mp3`
- `ticket-purchase.mp3`
- `success.mp3`
- `error.mp3`
- `draw-start.mp3`
- `draw-suspense.mp3`
- `winner-reveal.mp3`
- `jackpot-reveal.mp3`
- `notification.mp3`
- `luxe-ambient.mp3`

After licensed files are present, set `licensedAudioEnabled` to `true` in `src/audio/config.ts`. Keep clips short and compressed; music remains opt-in.
